# Gym Buddy

Gym Buddy is a Java application that allows users to create and track workouts, browse exercises, and receive exercise recommendations based on muscle groups.

## How to Run

1. Open the project in Eclipse.
2. Run `Main.java`.
3. Follow the instructions in the console menu.

## Features

- Create and log workouts
- Browse exercises by muscle group
- Add sets, reps, and weight
- Add custom exercises
- View workout history and progress
- Receive exercise recommendations
